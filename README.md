# Design IDE — downloads

Installers for the Design IDE closed beta. This repository holds only the installers; the source is private.

**Download page:** https://designer-ide-gateway.vercel.app

| Your Mac | File |
| --- | --- |
| Apple silicon (M1 and later) | `Design-IDE-arm64.dmg` |
| Intel | `Design-IDE-x64.dmg` |

Not sure which you have? Apple menu → About This Mac: "Chip: Apple M…" or "Processor: Intel".
Needs macOS 13 or later. The newest version is always under [Releases → Latest](../../releases/latest).
